# Tài liệu Backend ModMove

Toàn bộ tài liệu backend dùng chung cho Hiếu, Hoàng, Huy trong suốt dự án. Đọc theo thứ tự dưới trước khi code; khi tài liệu và code khác nhau, sửa tài liệu trong cùng PR.

| File | Nội dung | Khi nào cập nhật |
|---|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | Layer, CQRS, cấu trúc thư mục, mẫu use case, quy ước API | Đổi cách làm chung |
| [DECISIONS.md](DECISIONS.md) | Mọi quyết định nghiệp vụ nhóm đã chốt, và mục **Còn cần làm rõ** | Sau mỗi lần nhóm chốt |
| [TEAM-PLAN.md](TEAM-PLAN.md) | Ai làm gì, ranh giới thư mục, checklist từng người theo phase | Khi xong hoặc nhận việc |
| [api/README.md](api/README.md) | Endpoint đã có và bảng mã lỗi cho web/mobile | Mỗi endpoint hoặc mã lỗi mới |
| [REPORT4-CHANGES.md](REPORT4-CHANGES.md) | Chỗ code đã khác Report-3/Report-4, để sửa báo cáo khi nộp | Mỗi lần đổi schema hoặc luật so với báo cáo |

Ngoài thư mục này: [README.md](../README.md) (cách chạy dự án) và [CLAUDE.md](../CLAUDE.md) (quy tắc bắt buộc khi viết code).
