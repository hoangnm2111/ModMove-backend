# Quyết định thiết kế Backend

Đây là các quyết định nhóm đã chốt (bản cuối 2026-10-24, cập nhật kênh client và thông báo 2026-10-30, phía khách 2026-11-02, đối chiếu Report 3 ngày 2026-11-13, GPS tài xế 2026-11-18). Khi SRS/SDS khác file này, **làm theo file này**. Muốn đổi một quyết định: sửa file này trong một PR riêng, cả nhóm duyệt.

- **Thiết kế DB:** Report-4 mục 3 chỉ là bản thiết kế ban đầu. Nguồn sự thật của schema là **migration trong code** cùng file này.
- **Mã quyết định:** `B*`, `C*` là từ các buổi họp trước; `M*` và `1.x`–`9.x` là số mục trong tài liệu "Các vấn đề cần nhóm thống nhất".
- File này chỉ ghi quyết định. Tiến độ (đã làm hay chưa, ai làm) theo dõi duy nhất ở [TEAM-PLAN.md](TEAM-PLAN.md).
- Gặp chỗ chưa có quyết định: đừng tự đoán, hỏi nhóm rồi thêm vào file này trước khi code phần đó.

| GB-16 | Để nhận **mọi đơn hàng** (cả tiền mặt lẫn PayOS), ví phải `Active` và `DepositBalance ≥ REQUIRED_DEPOSIT` (200.000đ); riêng đơn tiền mặt cần thêm `DepositBalance ≥ hoa hồng đơn` (`COMMISSION_RATE × total_fee`).
